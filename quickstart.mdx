The Claude Council is a drop-in `~/.claude/` configuration — no build step, no package manager, no cloud account required. The installer is idempotent: any existing `~/.claude/` is moved aside to a timestamped backup before the new config lands, so you can re-run it safely at any time. From a fresh clone to a fully active Council takes about three minutes on any supported platform.

## Prerequisites

| Requirement | Minimum | Notes |
|-------------|---------|-------|
| **`git`** | Any recent | macOS: `brew install git`. Linux: distro package. Windows: [git-scm.com](https://git-scm.com/) |
| **`bash`** *(macOS / Linux / WSL2)* | 4.0+ | macOS ships with bash 3.2 — see the note below. Not needed on Windows-native. |
| **`claude` CLI** | Latest | Install separately from [Anthropic's docs](https://docs.claude.com/claude-code) |
| **`rsync`** *(macOS / Linux, optional)* | Any | Speeds up the install; falls back to `cp -R` if absent |
| **PowerShell** *(Windows only)* | 5.1+ | Ships with Windows 10/11; PowerShell Core 7+ also works |

## Installation Steps

<Steps>
  <Step title="Clone the repository">
    Clone The Claude Council repo to any convenient location — keep it a **sibling** of your projects, never a parent directory.

    ```bash
    # Using git
    git clone https://github.com/Nmor/the-claude-council.git

    # Or using the GitHub CLI
    gh repo clone Nmor/the-claude-council
    ```

    ```bash
    cd the-claude-council
    ```
  </Step>

  <Step title="Run the installer">
    The installer backs up any existing `~/.claude/`, copies the full config surface, creates runtime directories, and auto-detects installed IDEs.

    <CodeGroup>
      ```bash macOS / Linux / WSL2
      ./bootstrap/install.sh
      ```

      ```powershell Windows (PowerShell)
      # Allow script execution for this session
      Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process

      .\bootstrap\install.ps1
      ```
    </CodeGroup>
  </Step>

  <Step title="Verify the installation">
    Run the post-install self-test to confirm all rules, skills, agents, commands, and hooks are present and healthy.

    <CodeGroup>
      ```bash macOS / Linux / WSL2
      ./bootstrap/verify.sh
      ```

      ```powershell Windows (PowerShell)
      .\bootstrap\verify.ps1
      ```
    </CodeGroup>

    A healthy install ends with:

    ```text
    ✓ PASS — global Claude config is healthy.
    ```
  </Step>

  <Step title="Open any project in Claude Code">
    Open any project in a Claude Code-compatible IDE (VS Code, Cursor, Windsurf, JetBrains, or the `claude` CLI). The Council fires automatically on the next prompt — no project-level configuration needed.
  </Step>
</Steps>

## What the Installer Does

The installer performs these steps in order:

- **Backs up** any existing `~/.claude/` to `~/.claude.bak.<timestamp>` (unless `--force` is passed)
- **Copies** the config surface — rules, skills, agents, commands, hooks, templates, and `settings.json` — into `~/.claude/`
- **Creates** the runtime directories Claude Code expects: `audits/`, `plans/`, `file-history/`, `sessions/`, and others
- **Detects** installed IDEs (VS Code, Cursor, Windsurf, JetBrains) and offers per-IDE integration templates

## Installer Flags

| Bash flag | PowerShell flag | Effect |
|-----------|----------------|--------|
| `--dry-run` | `-DryRun` | Preview all actions without making any changes |
| `--force` | `-Force` | Skip backup and overwrite existing `~/.claude/` directly |
| `--no-ide` | `-NoIde` | Skip IDE integration detection and template copying |

Pass flags directly to the installer:

<CodeGroup>
  ```bash macOS / Linux / WSL2
  # Preview what would change without applying it
  ./bootstrap/install.sh --dry-run

  # Skip IDE integration
  ./bootstrap/install.sh --no-ide
  ```

  ```powershell Windows (PowerShell)
  # Preview what would change without applying it
  .\bootstrap\install.ps1 -DryRun

  # Skip IDE integration
  .\bootstrap\install.ps1 -NoIde
  ```
</CodeGroup>

<Note>
  **macOS bash version:** macOS ships with bash 3.2 (the last GPL2-era release). The installer requires bash 4.0+. Install a modern bash with `brew install bash`, then either re-launch your terminal or invoke the installer explicitly:

  ```bash
  /opt/homebrew/bin/bash bootstrap/install.sh
  ```
</Note>

<Tip>
  Run `./bootstrap/verify.sh --verbose` (or `.\bootstrap\verify.ps1 -Verbose` on Windows) to see the full verification block with per-check pass/fail lines across all eight phases: Layout, Inventory, Agent frontmatter, Skill presence, Hook executability, Cross-references, Contamination scan, and Code-graph validation.
</Tip>
